Is This Job Legit?

출제yebbis

대회 지문

최근 구직 활동을 하던 지우의 PC에서 수상한 흔적이 발견되었다.

디스크에 남아 있는 아티팩트를 분석하여 사건의 흐름을 재구성하고, 다음 네 가지 값을 구하라.
A. 사건의 최초 진입점이 된 Novera Data 채용 게시물의 client_msg_id
B. 실제로 승인된 snapshot을 생성한 실행에서 사용된 Git commit OID
C. 해당 gzip snapshot을 압축 해제한 원본 바이트의 SHA-256 해시값
D. 해당 staging 파일의 mft_entry-sequence-lcn-logical_size
D의 lcn은 unnamed non-resident $DATA의 첫 번째 extent가 시작되는 LCN을 의미하며, logical_size는 바이트 단위의 논리 크기를 의미한다. D에 포함되는 모든 숫자는 10진수로 작성한다.

확인한 A, B, C, D 값을 이용하여 다음 규칙에 따라 Flag를 생성하라.
preimage = lowercase(A) + "_" + lowercase(B) + "_" + lowercase(C) + "_" + D
flag = msgctf2026{lowercase_hex(SHA256(ASCII(preimage)))}
